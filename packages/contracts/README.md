# 共享契约

本目录保存前端、Flask 后端与 Python 算法共同遵守的机器可读契约。

## 权威顺序

1. `openapi.yaml`：HTTP 路径、请求、响应和错误的唯一事实来源；
2. `schemas/*.yaml`：由 OpenAPI 引用的数据结构；
3. `docs/api-contract.md`：面向组员的解释、示例和协作规则；
4. 各语言接口、类型和测试：必须实现上述契约，不得另起一套字段。

申请书只定义产品目标，不替代技术契约。出现分歧时先发 PR 更新本目录，获得
前端、后端和算法负责人审核后再改代码。

## 版本和兼容性

- 新增可选字段：补丁或次版本；
- 新增接口、必填能力：次版本；
- 删除/改名字段、改变单位或语义：主版本，并提供迁移说明；
- 百分数字段统一为百分点，金额字段统一标出币种和单位；
- 自动生成的客户端必须记录生成命令，不手改生成产物。

## PR 检查

- OpenAPI 及所有外部 `$ref` 可以解析；
- 示例使用六位 A 股/ETF 代码，不混用美股 ticker；
- Flask 返回、前端调用和算法 DTO 的字段与契约一致；
- 新字段有正常、边界和错误用例；
- 未实现策略标记为 `experimental` 或 `planned`；
- 配置建议保持 `advisoryOnly: true`，不加入真实交易能力。
