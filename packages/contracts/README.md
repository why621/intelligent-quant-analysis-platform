# 共享契约

本目录保存前端、Flask 后端与 Python 算法共同遵守的机器可读契约。

## 当前线上API契约：0.15.0（CR071，云端与Pages均已验收）

增量支持掩码注意力PPO/TD3架构与策略ID，保留全部原策略。每个候选独立训练和验收、只有显式发布配置才注册；目录最多六个组合模型，路径/唯一性/哈希门禁保持。HTTP请求结构不变。旧版CR070记录保留，详见[CR071记录](../../docs/cr071-masked-ppo-td3-2026-10-20.md)。

## 上一线上契约：0.14.0（CR070，云端与Pages均已部署）

新增实验策略portfolio_masked_sac，复用共享组合回测、当前配置排行榜与模拟接口。新增可选modelContext.representationLearning披露掩码注意力机制、训练内换池及未证明收益提升；不新增HTTP换池时间表。正式候选、哈希和327资产执行证据门禁保持。生产是否已切换见[CR070部署记录](../../docs/cr070-deployment-2026-10-20.md)。

## 上一版本：0.13.0（CR069，已部署）

新增POST /api/strategies/ranking及研究排行响应，复用完整回测请求；旧GET排行保留兼容。全目录组合模型在modelContext披露适用范围、范围证据、训练费用及请求可配成本。实现、调用方及边界测试已同步；已按用户授权部署云端；Pages已随PR #51合并发布，见[发布记录](../../docs/cr069-deployment-2026-10-15.md)。解释见[API说明](../../docs/api-contract.md)及[CR069验收](../../docs/cr069-universe-ranking-2026-10-15.md)。

## 权威顺序

1. `openapi.yaml`：HTTP 路径、请求、响应和错误的唯一事实来源；
2. `schemas/*.yaml`：由 OpenAPI 引用的数据结构；
3. `docs/api-contract.md`：面向组员的解释、示例和协作规则；
4. 各语言接口、类型和测试：必须实现上述契约，不得另起一套字段。

申请书只定义产品目标，不替代技术契约。出现分歧时先发 PR 更新本目录，获得
前端、后端和算法负责人审核后再改代码。

## 版本和兼容性

- 新增可选字段：补丁或次版本；
- 新增接口、必填能力：次版本；
- 删除/改名字段、改变单位或语义：主版本，并提供迁移说明；
- 百分数字段统一为百分点，金额字段统一标出币种和单位；
- 自动生成的客户端必须记录生成命令，不手改生成产物。

## PR 检查

- OpenAPI 及所有外部 `$ref` 可以解析；
- 示例使用六位 A 股/ETF 代码，不混用美股 ticker；
- Flask 返回、前端调用和算法 DTO 的字段与契约一致；
- 新字段有正常、边界和错误用例；
- 未实现策略标记为 `experimental` 或 `planned`；
- 配置建议保持 `advisoryOnly: true`，不加入真实交易能力。
