# 沪深300数据源首轮验证记录

日期：2026-09-07；关联CR-003、T-002、REQ-02/03/09、D-03。

## 结论

东方财富并非所有接口不可用，但目前不适合作为无备用的唯一数据源。发现两个不同问题：SDK指数历史函数依赖失败的前置列表；直接历史请求曾成功，却在第二轮失败。暂不能认定源站故障、封IP或跨境限制等具体责任。

中证官方成分名单可达；腾讯两只样本在两环境两轮均返回数据，但深市000开头个股的成交量转换存在高风险差异。数据可获取不等于通过质量验收，不在本轮切换生产来源。

- 本地两轮始于北京时间22:06、22:09；云端两轮始于UTC14:08:05、14:09:33（北京时间22:08、22:09）。属同一晚短间隔复测，不是跨日稳定性观察。
- 每轮实际11次HTTP请求，每个环境合计22次，两环境44次；包含SDK前置请求和重试。每次调度间隔至少2秒，连接/读取超时5/8秒，每项45秒硬截止、每项最多4次、脚本最多24次请求。
- Session不读取代理环境变量、不跟随重定向。此设置不证明本地VPN/TUN未参与网络，故单独记录云端结果。
- 云上仅将脚本流入现有容器执行，未写文件/业务缓存，未重建或重启服务。审批工具传输失败的尝试未执行，不计入请求数。
- 本地日志出现系统墙钟回拨，耗时使用monotonic；不依靠墙钟行序推断并发或网络时延。

## 数值与兼容性发现

- 600000的首轮东财与腾讯5条日线OHLC逐日一致，日期唯一递增；东财成交量乘100后与腾讯一致，符合该主板样本手/股差别。
- 该样本成交额最大绝对差约38元（数亿元基数），与不同精度相容；不推广为所有股票都一致，也不据此默认覆盖除权场景。
- 000001在腾讯SDK输出2026-09-07的volume=1087276、amount=1275606300、close=11.70，金额/成交量约1173，而将量乘100后约11.73。该检查是风险信号，不是复权价格与成交均价必然相等的假设。
- 已安装SDK源码写明volume输出为股，却将sz000前缀排除在乘100逻辑外，令平安银行这类个股与指数共用排除规则。源码和样本共同提示单位转换缺陷；须核对原始返回并增加资产类型区分测试后修复，不能对所有sz000或所有资产盲乘100。
- 当前项目适配器直接接收SDK的volume列，已有缓存可能受影响。尚未审计生产缓存；不能因历史状态ready推定成交量正确，也不能断言所有现有策略结果都受影响。
- 本轮未覆盖停牌、除权、上市初期、历史名单、指数成交量单位、全量300只及跨日持续性。T-002不能整体标为完成。
