云端07:30检查最近已完成交易日 → 有界采集/事件维护 → 逐资产质量与模块门禁 → 备份和原子发布 → 网页读取新版本。每个目标交易日最多尝试一次，休市或无新目标跳过；单次最多1637请求、采集5400秒，容器/外层限额继续保留。失败不自动同日重采，旧有效数据保留；发布失败回滚并写审计/systemd日志。没有另行配置邮件或消息推送告警。

持续模式没有累计四次停止条件，运行至明确停用，使用独立账本；原四次验收记录保留、未重置。至少2GiB磁盘可用才开始新候选，不自动清空证据。资源不足、日历覆盖不足或数据源变化仍可能导致当日失败，因此启用不等于保证每天成功。
