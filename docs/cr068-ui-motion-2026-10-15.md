# CR068 UI动态与交互验收

2026-10-15，本地实现完成，尚未推送或上线。

## 视觉与交互

参考[Cyberpunk 2077主菜单截图](https://www.mobygames.com/game/128136/cyberpunk-2077/screenshots/playstation-5/1086881/)的霓虹色、细线、切角和菜单反馈，在原有量化界面中使用黄/青强调与局部红色装饰。没有复制游戏Logo或图像素材。4.5秒柔和亮度变化只作用于装饰标记，12秒扫描仅在首屏低对比区域出现；正文、行情和图表保持静态可读。

- 独立InterfaceEffects组件：事件驱动requestAnimationFrame定位圆环，没有持续追踪循环；可点击目标扩圈、按下收缩；输入/选择框恢复原生指针，Tab/Escape/窗口失焦隐藏圆环。设备/系统偏好变化自动生效，卸载清理事件、观察器和动画。
- 两个界面开关分别控制动态与光标，保存在本地存储；存储不可用时不阻断页面。系统减少动态优先于用户开关，触屏/强制配色不用自定义光标。关闭动态也停止装饰伪元素及正在进行的模块动画。
- AssetPicker的分类筛选使用CSS Grid高度过渡，默认收起；aria-expanded、aria-controls、inert配套，隐藏内容不可键盘聚焦。收起不清除已选资产或类别，摘要显示启用类别数；股票/ETF基础类型和搜索仍直接可用。
- 按钮、筛选项、输入框反馈统一；原生锚点平滑滚动，不劫持滚轮。模块进入仅播放一次，无滚动时持续重绘。保持研究联动、费用和模型参数行为。
