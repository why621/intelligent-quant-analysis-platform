# 强化学习算法最新实现总结

更新日期：2026-09-20。范围为CR045—049，区分算法实现、真实模型训练、网页接入和线上验收。

## 已实现内容

- 修复原RL实现的持仓反馈偏差、买入费用透支、模型元数据校验不足及短历史越界。训练环境和回测共享执行逻辑，模型推理读取实际成交账户状态；旧执行版本模型须重训。
- 网页已开放PPO、DQN、SAC、DDPG四种实验性回测，均绑定各自已验证的模型。DQN使用满仓/空仓离散动作；PPO、SAC、DDPG输出仅做多的连续目标权重。
- 四种均可选择发布资产池内1–10只股票或ETF；初始资金等分，各资产独立推理、成交后合并净值。该能力不等于多资产联合训练或资产间动态调仓。
- 前端展示所选算法、模型和训练区间，提供“使用样本外日期区间”按钮；切换算法自动更新模型参数，历史结果继续对应原请求。
- 后端支持多模型部署清单并兼容旧PPO配置，校验算法、模型白名单、权重及元数据哈希、执行/特征版本、名单版本和逐资产历史；错误模型或无效数据不能静默放行。

## 模型与使用范围

四种已部署模型均基于510300训练，训练区间2025-09-09至2026-06-30。PPO沿用已验证权重；DQN、SAC、DDPG本次各以seed42、20000步完成真实行情训练及保存/加载验证。回测起始日不得早于2026-07-01，使用前复权，每只资产至少22根有效行情，其中20根预热。

所有模型仍标experimental、crossAssetValidated=false。已验证可运行与执行一致性，尚未证明跨资产收益有效性；未完成多种子长期绩效研究，未开放RL排行、次日模拟配置、多智能体或实盘交易。
